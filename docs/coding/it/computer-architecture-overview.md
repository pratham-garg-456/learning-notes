# Computer Architecture Overview

## Computer system layers

- A computer is divided into four main layers: hardware, operating system, software, and users.
- Hardware consists of physical components like laptops, phones, monitors, and keyboards.

## Operating system layer

- The operating system enables communication between hardware and software, allowing devices from different manufacturers to work together.
- The course covers major operating systems such as Android and Windows, explaining their components and navigation.

## Software and user interaction

- Software is the interface through which humans interact with computers, including apps, browsers, and word processors.
- The user layer is vital. It emphasizes the human element in IT, including responding to user needs and troubleshooting.
