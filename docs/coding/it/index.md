# IT Fundamentals

Notes from the Google Technical Support Fundamentals course.

For an IT Support Specialist there is no such thing as a typical day, since the puzzles and challenges are always new and interesting. But in general, we make sure that an organization's technological equipment is running smoothly.

## Topics

- [Computer Architecture Overview](computer-architecture-overview.md): the four layers of a computer system.
- [Programs, the CPU, and the Memory](programs-cpu-and-memory.md): how instructions get from storage to the processor.
- [CPU](cpu.md): sockets.
- [RAM](ram.md): DRAM, DIMMs, SDRAM, and DDR.
- [Motherboards](motherboards.md): chipset, PCIe, and form factors.
- [Power Supplies](power-supplies.md): AC to DC, voltage, current, and wattage.
- [Storage: Hard Drives](storage.md): data units, HDDs, SSDs, SATA, and NVMe.
- [Drivers and BIOS](bios-and-drivers.md): how a computer starts and talks to devices.
- [Peripherals and Ports](peripherals-and-ports.md): USB, network connectors, and legacy connectors.
- [Files and File Systems](files-and-file-systems.md): NTFS, EXT4, blocks, metadata, and extensions.
- [Character Encoding](character-encoding.md): ASCII and UTF-8.

See also [Basics](../cpp/basics.md) in the C++ notes for bits, bytes, and addresses.
