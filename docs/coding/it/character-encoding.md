# Character Encoding

Character encoding assigns binary values to human-readable characters, acting like a dictionary for computers to interpret text.

## ASCII

Uses 1 byte per character.

The oldest standard, representing English letters, digits, and punctuation using 128 values (0 to 127) out of the 256 possible in a byte.

## UTF-8

Uses a variable number of bytes to represent characters, enabling representation of emojis and many more symbols.

## Practice Questions

??? question "1. What is character encoding?"

    A mapping of binary values to human-readable characters, like a dictionary computers use to interpret text.

??? question "2. How does ASCII differ from UTF-8?"

    ASCII uses 1 byte per character and covers only English letters, digits, and punctuation (128 values). UTF-8 uses a variable number of bytes per character, so it can represent emojis and many more symbols.
