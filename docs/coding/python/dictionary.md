# Dictionary (Hashmap)

Each key in dictionary is unique and maps to its value.

#### Creating Hashmap

```python
my_dict = {
    "apple": 1,
    "banana": 2,
    "orange": 3
}
```

## Practice Questions

??? question "1. What is a Python dictionary?"

    A hashmap where each key is unique and maps to its value.

??? question "2. How do you create one?"

    With curly braces of key-value pairs, for example `{"apple": 1, "banana": 2, "orange": 3}`.
