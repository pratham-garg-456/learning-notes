# Generative AI Tools for Workplace Tasks

## Conversational AI tools

Conversational AI tools process text requests and generate text responses. Their ability to simulate human-like conversations lets them provide detailed and nuanced answers on a wide variety of subjects.

Uses include researching online information, translating between languages, analyzing long documents, brainstorming ideas, planning schedules, proofreading text, and much more.

Example tools:

- [**Anthropic Claude**](https://www.anthropic.com/product): can complete problem-solving tasks, like finding mathematical solutions, translating between languages, and summarizing long documents. Stand-alone.
- [**Gemini**](https://gemini.google.com/app): chat to start writing, planning, learning, and more with Google AI. Both stand-alone and integrated.
- [**Microsoft Copilot**](https://www.microsoft.com/en-us/edge/features/copilot?form=MT00IS): integrated with Microsoft Edge, it can help with online searches, compare products, and summarize web page content. Both.
- [**ChatGPT**](https://openai.com/chatgpt): can generate ideas, plan schedules, debug code, and proofread text. Stand-alone.

## Code-generative AI tools

These tools help with software development tasks across programming languages. They function as an AI **pair programmer**: offering suggestions, debugging errors, finding solutions to coding challenges, and more.

| Tool | Description | Example industries | Stand-alone or integrated |
| --- | --- | --- | --- |
| [Gemini Code Assist](https://codeassist.google/) | A plugin for popular IDEs that lets users prompt Gemini to generate code, troubleshoot bugs, and answer questions about software development. | Software development, IT, web development, systems administration | Integrated |
| [GitHub Copilot](https://github.com/features/copilot) | A plugin for popular IDEs and built into GitHub. Can write and suggest code, suggest descriptions for pull requests, translate multiple languages into code, and index repositories. | Data science, software development, web development | Integrated |
| [Tabnine](https://www.tabnine.com/) | A plugin for many popular code editors to help speed up delivery and keep code safe. | Data science, software development, web development | Integrated |
| [Jupyter AI](https://jupyter-ai.readthedocs.io/en/latest/) | A built-in tool for the open-source Jupyter platform with a chat interface to generate code, fix coding errors, and ask questions about files. | Data science, software development, web development | Integrated |

## Practice Questions

??? question "1. What can conversational AI tools do?"

    Process text requests and generate text responses, simulating human-like conversation. Uses include researching, translating, analyzing long documents, brainstorming, planning schedules, and proofreading.

??? question "2. What is an AI pair programmer?"

    A code-generative AI tool (like GitHub Copilot or Gemini Code Assist) that offers suggestions, debugs errors, and finds solutions to coding challenges while you write code.

??? question "3. Which tools generate images, and which generate speech or video?"

    Images: Adobe Firefly, Canva Magic Design, DALL-E, Midjourney. Speech: ElevenLabs. Video: Runway.

??? question "4. What does stand-alone versus integrated mean for an AI tool?"

    A stand-alone tool is used on its own (like ChatGPT or Grammarly). An integrated tool is built into another product or plugin (like Notion AI or GitHub Copilot).
