# Functions and Formulas

| Function | What it does |
| --- | --- |
| `SUM` | Adds the values |
| `AVERAGE` | Averages the values |
| `MAX` | Largest value |
| `MIN` | Smallest value |
| `COUNT` | Counts the number of cells that are numeric only |
| `COUNTA` | Counts the number of cells that are not empty |
| `COUNTBLANK` | Counts blank cells |

## Practice Questions

??? question "1. What is the difference between COUNT, COUNTA, and COUNTBLANK?"

    `COUNT` counts only numeric cells, `COUNTA` counts cells that are not empty, and `COUNTBLANK` counts blank cells.
