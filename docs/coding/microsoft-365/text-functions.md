# Text Functions

RIGHT, LEFT, MID
UPPER, LOWER, PROPER

LENGTH, TRIM

CONCAT, TEXT JOIN

## Practice Questions

??? question "1. Which functions take part of a text?"

    `LEFT`, `RIGHT`, and `MID`.

??? question "2. Which functions change case?"

    `UPPER`, `LOWER`, and `PROPER`.

??? question "3. Which functions measure and clean text, and which combine text?"

    Length and `TRIM` measure and clean it. `CONCAT` and `TEXTJOIN` combine text.
