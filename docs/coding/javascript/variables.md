# Variables

## What is a variable?

- My name is **Pratham** and I tell you a few facts about me (like my name, where I live, or my goals).
- I ask you to **remember** those facts so I don't have to repeat them every time we talk.
- Later, instead of saying my full details again, I can just refer to them as "my name", "my city", or "my ambition", and you'll still know what I mean.
- That is exactly what **variables** do in programming: we give a piece of data a **name**, and the computer **stores it in memory** so we can reuse it anytime by using that name (for example `name = "Pratham"`).

```javascript
var myName = "Pratham";
```

See also [Variables and Constants](../cpp/variables-and-constants.md) in the C++ notes and the scope topic in the [JavaScript study plan](index.md).

## Practice Questions

??? question "1. What is a variable, in your own words?"

    A name given to a piece of data, which the computer stores in memory so we can reuse the data any time by using that name.

??? question "2. What does this line do: var myName = Pratham?"

    It creates a variable called `myName` and stores the value "Pratham" in it, so later code can refer to `myName` instead of repeating the value.
