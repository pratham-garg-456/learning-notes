# History of Browsing

Resource: [Difference Between Compiler and Interpreter](https://www.youtube.com/watch?v=_C5AHaS1mOA)

- Netscape lost the browser war to Microsoft Internet Explorer.
- In 1998, Netscape released its source code, forming the Mozilla Organization, which developed the Gecko engine that powers Firefox today.
- Early HTML websites were mostly static ("all form and no function").
- Any needed functionality (searching or retrieving data, doing calculations, unit conversions) required sending a request to a server.
- The server handled the computation and business logic.
- The server then returned a new web page containing the updated data.

!!! tip
    **Key idea:** the browser is basically a viewer, not a thinker.

- Netscape wanted a more dynamic web with animations and real-time user interaction.
- To achieve that, code needed to run directly in the browser instead of relying on the server.
- Netscape's solution was to create a small scripting language to run in the browser.

The language's names over time:

**LiveScript → JScript → ECMAScript → JavaScript**
