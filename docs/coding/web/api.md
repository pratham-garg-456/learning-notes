# API

## Application Programming Interface

A set of rules and protocols that define how different pieces of software interact with each other.

## REST API

It uses HTTP protocols and the methods: GET, POST, PUT, PATCH, DELETE.

See also [REST, GraphQL, gRPC](../../chapter-3/rest-graphql-grpc.md) in the System Design notes.

## API authentication

Different types of authentication, in order of security:

1. No authentication
2. Basic authentication: `username:password`
3. API key authorization
4. Token-based authentication

## Practice Questions

??? question "1. What is an API?"

    A set of rules and protocols that define how different software interacts with each other.

??? question "2. Which HTTP methods does a REST API use?"

    GET, POST, PUT, PATCH, and DELETE.

??? question "3. List the four types of API authentication from least to most secure."

    No authentication, basic authentication (username and password), API key authorization, and token-based authentication.
