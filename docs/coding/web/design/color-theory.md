# Color Theory

Resources: [Color Hunt](https://colorhunt.co/) and [Adobe Color wheel](https://color.adobe.com/create/color-wheel).

When picking colors, we have to be aware of the mood of our color palette.

## Combining colors

### Analogous colors

Pairing colors that are close to each other.

### Complementary colors

Used to make something pop out.

!!! tip
    Don't use complementary colors for text. Use them for logos, icons, or things you really want to stand out.

## Practice Questions

??? question "1. Why should you think about mood when picking a color palette?"

    Colors carry a mood, so the palette should match the feeling you want the design to give.

??? question "2. What are analogous colors?"

    Colors that are close to each other, paired together.

??? question "3. What are complementary colors good for, and what should you avoid using them for?"

    They make things pop out, so use them for logos, icons, or things you really want to stand out. Don't use them for text.
