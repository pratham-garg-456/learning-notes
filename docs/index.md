# Learning Notes

Everything I learn, written down so I can find it again. Each note explains a concept in plain words, grounds it in a real example, and ends with practice questions to test myself.

## Areas

- **[Coding](coding/index.md)**: system design, languages, data structures, algorithms, tooling, and habits of good engineers. System design is the most developed topic so far.
- **[Languages](languages/index.md)**: human languages I am learning, with vocabulary, grammar, and phrases.
- **[Money](money/index.md)**: earning, saving, investing, taxes, and how to think about risk.
- **[People Skills](people-skills/index.md)**: communication, listening, feedback, conflict, and working with others.

## How notes are written

Every note follows the same shape, described in the [note template](appendix/note-template.md):

1. **What it is** in one or two plain sentences.
2. **A concrete example** from something real, not an abstract definition.
3. **Details**, with a diagram when a picture beats a paragraph.
4. **Practice questions** in collapsible blocks so I can quiz myself.
